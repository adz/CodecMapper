# Modeling Common Schema Patterns

Use this page as a quick jump list when you know the kind of schema you need and want the closest matching example.

All examples stay on the stable authored DSL:

```fsharp
Schema.define<'T>
|> Schema.construct ctor
|> Schema.field ...
|> Schema.build
```
